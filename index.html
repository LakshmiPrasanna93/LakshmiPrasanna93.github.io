AI agents & LLM products

AI agentLaunch

Taking an enterprise AI assistant to GA

Problem
Admins spent too long hunting for answers across complex admin screens.
What I did
Scoped a read-only Q&A agent with tool calls per core module and role-based access enforced by the user's token. Evaluated a multi-agent supervisor design and deferred it because of the latency cost.
Outcome
Shipped single-agent to production, which set up a safe base for v2.
EvalsQuality

Eval-driven launch gates

Problem
"Looks good in the demo" isn't a launch criterion for enterprise AI.
What I did
Designed a 200+ case eval suite with P0 gates: tool selection ≥95%, parameter accuracy ≥90%, response quality ≥4/5, guardrails 100%. Known backlog bugs are kept out so the scores stay honest.
Outcome
Gave the team an objective go/no-go bar and a regression net for every prompt change.
CostPrompting

Cutting agent token cost ~40% without losing quality

Problem
Multi-agent instruction files were long, full of prohibition lists, and expensive on every call.
What I did
Rewrote each sub-agent with rule IDs, gold examples in place of "don't" lists, and handoffs that carry IDs between agents.
Outcome
About 40–45% fewer input tokens per agent, checked against the same eval gates.
AI UXStreaming

Rendering tables in a streaming chatbot

Problem
Tables streamed row by row arrived with unclear row boundaries and made the page jump.
What I did
Used evidence to show that tables add no generation latency. Chose to stream prose immediately and hold each table until it's complete, with a loading indicator.
Outcome
A stable, readable chat UI at no cost to perceived speed.

Admin, trust & self-serve platforms

CompliancePlatform

Audit logs, from zero to GA

Problem
Customers couldn't see who changed what, and the history that did exist was spread across legacy modules.
What I did
Ran customer discovery on retention needs, usage patterns and pricing sentiment. Wrote PRDs for field-level diffs, grouping of bulk updates, tiered retention (soft and hard archive) and tombstones for deleted entities.
Outcome
Phase 1 went GA across three core modules and Phase 2 is shipped. Legacy unification is planned next.
Access controlDiscovery

Roles & permissions gap analysis

Problem
Gaps in the permission model blocked enterprise admins from delegating safely.
What I did
Audited 48 requirements across 9 story areas. Found a critical missing story (role deletion), and ruled out a composite-role approach as too complex for the value it added.
Outcome
A complete, prioritized PRD that engineering could build against with confidence.
ConfigurationArchitecture

Hierarchical settings with inheritance

Problem
Large customers needed settings applied at the group level, with overrides that can be inherited.
What I did
Shipped group-level provisioning with pin/unpin overrides and reset-to-inherit. Split the plan into a short-term extension of the UI and a long-term, config-driven metadata registry, and drafted the engineering spike for it.
Outcome
Unblocked large accounts now, with a path off hardcoded settings screens.
Self-serveAnalytics

Self-serve setup for AI-powered alerts

Problem
Customers relied on support to turn AI detection alerts on, off or tune them.
What I did
Delivered Phase 2 of self-serve configuration. Instrumented analytics with a dirty-flag pattern so only real changes are tracked. Wrote warning copy to keep cross-domain alert windows consistent.
Outcome
Fewer support tickets, and clean usage data to prioritize what's next.

How I work

The principles I bring to AI products.

  1. Evals before launch dates

    A model is ready when it passes the gates, not when the sprint ends. I define P0 thresholds up front.

  2. Ship the boring version first

    Single-agent, read-only, scoped by role. Complexity gets added only when the data asks for it.

  3. Tokens are a product cost

    Latency and spend are UX. I treat prompt size the way I'd treat page weight.

  4. Trust is a feature

    Audit trails, permissions and guardrails are what make an AI agent safe for enterprise use.
